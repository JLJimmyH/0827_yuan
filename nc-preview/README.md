# 銑床預演台

Fanuc 加工中心 G-code 的網頁版預演、檢錯與編輯工具。Chrome／Edge 直接開 `index.html` 就能用（`file://` 可）：純前端、不裝套件、不連外，程式檔不離開這台電腦。

> 只吃**銑床／加工中心**的程式，車床不支援（G 代碼體系不同）。
> **預演，不是機台模擬器。** 刀長補正（H）當 0、G54–G59 視為同一原點、只支援 G17 平面、不算加減速與前瞻。**上機前的 dry run 照做。**

## 怎麼用

1. **開檔** —— 按「開檔…」或把檔案拖進視窗，編碼自動判斷（UTF-8 → Big5），沒有副檔名也可以。
2. **填刀具表** —— 填實際直徑。用 G41／G42 的**一定要填 D 值**。標`預設`的欄位是猜的，成品圖會不準。
3. **填素材** —— Project → 素材填真實尺寸。沒填就用切削範圍推估，靠素材的檢查（撞刀、重切削、廢料）一律降成警告。
4. **看右下「錯誤清單」** —— 37 條規則，點路徑或點錯誤都會跳到那一行。

左欄 Project 五個子頁（程式／素材／刀具表／刀庫／機台）是改東西的地方，右下狀態條四個分頁（總覽／游標行／作業摘要／錯誤清單）是看結果的地方。刀具表與設定以程式 O 號存在瀏覽器，下次開同一支自動帶回。

點頂列標題（銑床預演台 ⓘ）開「關於」，裡面有版本號與問題回報信箱。**回報問題請附上版本號。**

## 一定要知道的限制

- **M98／M99 副程式不展開** —— 那一段沒有預演，素材與碰撞結果不完整。
- **材料是高度圖** —— 側凹、鑽穿之後的孔壁表現不出來。
- **格網只涵蓋素材的 XY 範圍** —— 完全落在素材外的治具（虎鉗鉗口）抓不到撞機。
- **推估素材判不出切穿**，也就沒有廢料判定；要看廢料就得填真實素材高度。
- 巨集（G65／G66）、G68 旋轉、G16 極座標、G51 比例／鏡像：認得、出警告、**不模擬**。
- 時間估算不含加減速、換刀、主軸啟停，實際會更久。

## 結果準不準，看你填了多少現場資料

程式檔只寫「走到哪裡」，機台裡的東西它一概不知道 —— 真實素材尺寸與擺放、夾治具位置與高度、刀具實際直徑與角度、各 D 號的機台現值、G0 速率與 G83 餘隙。註解寫 12MM 實際裝 8MM，補正後的路徑就是錯的。

素材範圍和程式對不上（例如孔落在素材外面），通常是素材尺寸或原點位置填錯，不是程式有問題。

## 開發

Node 22 以上。只用內建模組，沒有 `package.json`、沒有建置流程。

```bash
node --test "test/*.test.mjs"      # 全部測試
node tools/check-samples.mjs       # samples/ 的示範程式不能有 error
node tools/shot.mjs [範例[:hash]]  # headless 截圖，順便抓 console 錯誤
```

`js/core/*` 是不碰 DOM 的核心（Node 可測），`js/ui/*` 才碰 DOM，載入順序固定寫在 `index.html`。

**改核心模組前先讀 [`docs/CONTRACT.md`](docs/CONTRACT.md)**，尤其最後一節「整合決議」—— 那些是踩過坑之後定下來的規則。其餘腳本、檔案結構與效能基準見 [`docs/USAGE.md`](docs/USAGE.md#開發附錄)。
