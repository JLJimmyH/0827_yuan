# NC 預演台

Fanuc 加工中心 G-code 的網頁版預演、檢錯與編輯工具。

丟一支 NC 程式進去，它會把路徑畫出來、把材料一格一格切給你看，然後列出這支程式裡可能出事的地方：語法、模態衝突、刀徑補正、固定循環、剛性攻牙、block skip 開關造成的差異、撞刀風險、切削條件。

純前端。用瀏覽器直接開 `index.html` 就能用，不必架伺服器、不必裝套件、不會連外，程式檔不會離開這台電腦。

> 這是**預演**，不是機台模擬器。刀長補正（H）當成 0、G54–G59 視為同一原點、只支援 G17 平面、不算加減速與前瞻。
> **四軸（A）程式**用圓棒素材模擬，成品、殘料、碰撞都算得出來，但一樣表現不了側凹（見「已知限制／第四軸」）。**上機前的 dry run 照做。**

## 怎麼用

### 1. 開起來

用 Chrome 或 Edge 直接開 `index.html`（`file://` 就可以）。一進來會自動載入第一支內建範例，工具列的「範例」下拉可以切換四支示範程式。

### 2. 把程式丟進來

- 按「開檔…」選檔案，或把檔案**直接拖進視窗**任何地方。
- 檔名沒有副檔名也沒關係（機台傳出來的檔案常常這樣）。
- 編碼會自己判斷：先試 UTF-8，不是就當 Big5 讀，都不行才退回逐位元組。

### 3. 填刀具表和素材（決定成品圖準不準）

程式裡只有 `M6T11(12MM)` 這種註解，機台裡的實際刀具資料程式看不到，所以：

- **刀具表**分頁：每一列後面的小標籤寫著這個值是哪來的——`註解`（從程式註解讀的）、`動作`（從切削動作反推的）、`預設`（猜的）、`手填`（你填的）。看到`預設`就表示那格是猜的，成品圖會不準。
  - 用到 G41/G42 的程式，**D 補正的半徑一定要填**。沒填的會在錯誤清單出現黃色的「需輸入 D 值」。
  - 倒角刀（`10V`、`5V`）不會拿公稱直徑÷2 當補正量——倒角刀真正的補正量取決於刀尖高度，只能你填。
  - `★` 是常駐刀（開機就在刀庫、不用換的）。`定位器?` 表示這把刀在程式裡沒有註解也沒有任何切削動作，可能是拿來測距的空刀位。
- **素材與設定**分頁：素材沒填的話會拿切削範圍往外推一個刀半徑當毛胚，並標成「由程式推估」。推估的素材本來就不會等於真實毛胚，所以凡是靠素材判斷的檢查（撞刀、重切削、殘料）都只會給黃色警告、不會給紅字，而且每一則都會註明「此判定依據推估素材」。**填了真實尺寸再看，那些警告才有意義。**

刀具表和設定會存在瀏覽器裡（刀具表以程式的 O 號為 key），下次開同一支程式會自己帶回來。`file://` 下瀏覽器有時會擋掉儲存，擋掉時狀態列會寫「刀具表無法存入瀏覽器」。

### 4. 看成品和錯誤

- **右上視圖**：俯視是把模擬完的材料用色階畫出來，越淺表示越接近頂面、越深表示切得越深。切「剖面 X／剖面 Y」再拉「剖面」滑桿，可以看某一刀的斷面形狀。
- **視圖是左右並排的：左邊 2D、右邊 3D**。切到「剖面 X／剖面 Y」再拉「剖面」滑桿，右邊 3D 會出現一片橘色的平面標出這一刀切在哪裡；
  勾著「3D 剖切」的話還會把擋住斷面的那半邊切掉，直接看到斷面——和左邊那張剖面圖是同一刀。
  切掉哪一邊是**固定的**，不會因為你轉視角或拉滑桿就自己換邊（那會讓人一瞬間認不出在看哪一面）。
  剖面拉到工件端面附近時留下來的那塊會很薄，這時候按工具列的「換邊」換成留另外一邊。
  中間那條分隔線可以拖（雙擊回到一半一半）；不想並排就把「並排 3D」取消勾選，2D 會佔滿整塊。
- **俯視與展開圖沒有剖面**：俯視就是從上往下看整塊成品，剖面滑桿會停用，3D 也不會標平面。
- 「模擬到」滑桿可以只看做到第幾把刀為止的樣子，用來確認某一刀該切的有沒有切到。
- **錯誤清單**分頁：紅色錯誤排最前面。同一個原因、只是發生在很多行的，會摺成一列並在後面標 `×17`；展開就看得到全部行號，點行號直接跳過去。想一行一行看就勾「逐行列出」。
- 點視圖裡的路徑會跳到對應的那一行；點錯誤清單也會跳到那一行；游標移到哪一行，左下就顯示那一行**執行後**的模態狀態（G90/G91、G41 D、F、S、目前位置…）。
- 編輯器右邊那一欄是每一行的執行摘要（`G1 90 G41D11 F150 Z-2`），可以直接看出這一行到底跑在哪個模態下。

### 5. 改、然後存回去

編輯器可以直接改。停手約 0.3 秒會重跑路徑與檢查，1 秒後重跑材料模擬，所以邊改邊看得到結果。

改完按「存檔」就會用**原本的檔名**下載回來（沒有副檔名的也照原樣），行尾維持原檔的 CRLF 或 LF。「複製」是把整支程式複製到剪貼簿。

### Block skip（節首斜線）

工具列的「Block skip」是這個工具的重點功能之一：

- **開關關**：所有節都執行。
- **開關開**：`/` 的節跳過。
- **多斜線忽略**：`//` 以上的節永遠不執行、單斜線的照跑。

切換之後路徑、成品、檢查全部跟著換。R06 會自動比較兩種情境：某一節被跳過以後，下一個動作會不會變成「在材料裡橫著切過去」——內建範例的 `demo-plate`、`demo-pocket` 就是這種寫法。

### 網址參數（做簡報或截圖時方便）

`index.html#sample=demo-plate&scenario=on&mode=sectionY&section=-20&tab=diag`

再加 `&split=0` 關掉右邊的 3D、`&clip=0` 只標剖面平面不剖開。

```
│ 工具列：開檔 範例 存檔 複製 Block skip        狀態列＋錯誤計數 │
├───────────────────────────┬─────────────────────────────────┤
│ 程式（編輯器）             │ 俯視／剖面X／剖面Y／3D／展開圖   │
│  行號＋錯誤標記            │ 剖面位置｜模擬到第N把刀｜並排｜剖切│
│  程式本文                  │ ┌──────────┬──────────┐│
│  每行執行摘要              │ │ 2D       │ 3D＋剖面 ││
│                            │ └──────────┴──────────┘│
├───────────────────────────┼─────────────────────────────────┤
│ 游標行的模態狀態           │ 刀具表｜錯誤清單｜作業摘要｜素材與設定│
└───────────────────────────┴─────────────────────────────────┘
```

- **刀具表**：T 號、程式註解、型式、直徑、角度、刃長、角R／頸徑、用到的 D 號與補正值，每格標來源。
  型式有 22 種（平刀、球刀、圓鼻刀、面銑刀、外R成型刀、倒角刀、T型刀、錐度刀、鳩尾槽刀、糖球形銑刀、
  鑽頭、鉸刀、搪孔刀、右牙刀、左牙刀、中心鑽、點鑽、沉頭孔鑽、魚眼孔鑽、雕刻刀、木工鑽頭、未定義），
  選了圓鼻刀、T型刀這類刀會多出「角R／頸徑」欄要填——沒有這兩個值就畫不出真正的刀形。
- **錯誤清單**：嚴重度篩選（錯誤／警告／需輸入／訊息）、「只看 skip ON 差異」、文字搜尋。展開每一則會看到「這代表什麼、會發生什麼、建議怎麼改」，有機台警報號的會標出來（例如 PS0041）。少數規則附「套用修正」。
- **作業摘要**：以換刀（M6）分段，每段的刀具、H／D、判斷出來的用途（面銑／輪廓／鑽孔／攻牙／倒角…）、最深 Z、F、S、行號範圍、估計時間。
- **素材與設定**：素材範圍、Block skip 細節（多斜線怎麼算、哪幾級算開）、機台設定（換刀前是否需要 M5、小數點慣例、G0 速率、下刀進給上限、補正先讀節數）、模擬格距。

## 開發與測試

需要 Node 22 以上（只用內建模組，沒有 `package.json`、沒有 npm 相依）。

```bash
cd nc-preview
node --test "test/*.test.mjs"          # 全部測試
node --test "test/rules.test.mjs"      # 單一模組
```

測試用 `test/load.mjs` 把 `js/core/*.js` 依序 eval 進同一個 global，再對 `test/fixtures/` 裡的程式做 golden test（那個目錄不進版控，沒有的時候 golden test 整組自動 skip，其餘測試照跑）。UI 模組（panels、editor、view2d）用測試檔裡自帶的極小假 DOM 測純邏輯。

其他工具：

```bash
node tools/diag-report.mjs             # test/fixtures 每支程式的診斷總表（--no-sim / --cell=0.25 / --all / --detail）
node tools/shot.mjs                    # 用 headless Chrome/Edge 截圖到 test/shot-<範例>.png，順便抓 console 錯誤
node tools/shot.mjs demo-plate:mode=sectionX&tab=diag
node tools/make-samples.mjs            # 從 samples/ 重新產生 js/ui/samples.js
node tools/check-samples.mjs           # 確認 samples/ 的示範程式沒有 error
```

改核心模組之前先讀 `docs/CONTRACT.md`，尤其最後一節「整合決議」——那些是踩過坑之後定下來的規則（例如 G83 的餘隙方向、倒角刀不能用公稱直徑當補正量、推估素材不報紅字）。

### 效能與記憶體基準（回歸時拿來對）

一支 1593 行、15 把刀、3582 段的程式，兩個情境各跑一次模擬，Node 22 / Windows：

| 格距 | 格數 | 快照份數 | 快照佔用 | 整趟 |
|---|---|---|---|---|
| 0.5 mm | 0.17 M | 22 | 14 MB | 約 0.3 s |
| 0.25 mm | 0.68 M | 22 | 58 MB | 約 0.4 s |
| 0.1 mm | 4.27 M | 3 | 49 MB | 約 1.7 s |

不含模擬的那一趟（tokenize + interpret ×2 + geometry ×2 + 推估素材）約 50 ms，契約目標是 200 ms。

**0.1 mm 那一列是特別要盯的**：快照份數是照「位元組預算」（預設 64 MB，
`settings.snapshotBudgetBytes`）算出來的，不是固定 25 份。以前固定存 25 份，
格距選 0.1 mm 時光是 heightmap 就會吃掉 750 MB，瀏覽器分頁大概率被打爆
（重新分析時峰值還要再乘二，因為上一輪的結果還被抓著）。改動 `simulation.js`
的快照邏輯之後，請重新量這一列。

瀏覽器裡連跑 6 次完整分析（含模擬），`usedJSHeapSize` 穩定在 43 MB，沒有累積。

## 已知限制

**解譯**

- 刀長補正（G43 H）只檢查有沒有寫，Z 一律當成程式寫的值。
- G54–G59 視為同一個原點（沒有偏置資料）。
- 只支援 G17 平面；G18／G19 的圓弧會退化成直線並**警告**（程式本身合法，是工具做不到，所以不用紅字）。
- G92／G10 的座標系位移不模擬；G53 機械座標不畫路徑，只把位置視為到了參考點附近並警告。
- G95（每轉進給）只記狀態，不換算進給值。
- **M98／M99 副程式不展開**：遇到 M98 會出一則警告說明「這一段路徑沒有預演，素材與碰撞結果不完整」。
  要看完整路徑，請先把副程式內容貼進主程式。
- G65／G66／G67 巨集、G68 座標旋轉、G16 極座標、G51 比例、G51.1 鏡像、G07.1 圓筒插補都**不模擬**，
  但都認得（出警告，不會報 PS0010），而且不會拿那一節的座標字去畫幽靈路徑。
- G61／G62／G63／G64／G09／G15／G69／G50 這些只影響加減速或取消模態的碼，路徑與實機相同，只出一則提示。
- 固定循環的重複次數 K／L：G91（增量）時會照增量展開成多個孔；G90（絕對）時只畫一個孔並警告
  （實機是原地重鑽，形狀一樣、時間會少估）。
- G87 背搪孔只近似成「快速下到孔底、進給往上搪」，主軸定向與 Q 偏移量沒有模擬。
- `,C`／`,R` 只展開接在直線後面的；接在 G2/G3 的會警告「未展開」。

**第四軸（A）**

繞 X 軸的臥式分度頭（工件是夾在夾頭上的圓棒）。程式有 A 且真的轉過時，頂列會出現一條橫幅。

- **路徑畫得出來**，而且每一張圖用的都是同一套工件座標，不會互相矛盾：
  - **展開圖** — 圓棒表面攤平：橫軸是軸向位置、縱軸是角度。分度角度等不等分、孔的軸向位置對不對，
    這張圖一眼就看得出來。**四軸程式先看這張。**
  - **剖面 X** — 圓棒的**橫截面**：孔從圓周指向中心，滑鼠移過去會顯示離軸心多遠、切進去多深。
  - **剖面 Y** — 沿軸向的**縱剖面**：這個 Y 上圓棒被削成什麼厚度，槽多深、貫穿孔穿到哪。
  - **俯視** — 從上方看那根圓棒：分度孔排不排得齊、槽銑在哪一段，看這張最直觀。
    顏色是「離軸心多遠」，沒切過的地方一律是表面色；棒身以外是空的（透明）。
  - **3D** — 畫一根真正的圓棒成品，可以轉來轉去看；並排時跟著剖面滑桿一起剖開。
- 圖上的**刀路都是直線**，跟實際機台一樣（刀只走 XYZ，是工件在轉）。分度轉動時刀相對工件掃過的
  那圈弧另外歸類，由「工件轉動軌跡」開關控制、**預設不畫**——它容易被誤讀成「刀在轉彎」。
  要確認分度會不會掃到刀時再打開。
- **成品、殘料與碰撞都算得出來。** 四軸的素材是圓棒，用「(軸向位置, 繞一圈的角度) → 離軸心多遠」
  的模型模擬：3D 會畫出真正的成品（圓棒上有孔和槽），俯視與兩張剖面都是從同一份模擬攤出來的，
  碰撞檢查也照常跑。（早期版本沒有圓棒模擬，俯視與剖面 Y 只能停用；現在不必了。）
- 直徑沒填的話會用程式推估（取切削段離軸心最遠的距離）。要準的話到「素材與設定」→ 第四軸填實際直徑。
- 鑽穿工件的孔，對面那個開口也會挖出來。做不到的是**側凹**——貫穿孔中間的孔道內壁、
  鳩尾槽那種表現不出來（跟三軸的高度圖同一個限制）。
- 會抓的四軸專屬問題：轉動時刀尖還沒退到安全高度（分度撞機第一名，G99 只退到 R 點就轉也算）、
  `A90` 沒小數點（DPI=0 時讀成 0.09 度，分度等於沒做）、刀徑補正生效中轉 A、程式結束沒把 A 轉回 0。
- 分度（轉到角度停住再切）與連續四軸（A 與 XYZ 同時進給）由程式自己判斷；後者連路徑都畫不出來，會標明。
- 三軸程式寫了 `A0.` 但從頭到尾沒轉 → 路徑完全正確，不會有任何提醒，展開圖按鈕也保持停用。
- 程式裡的 Z 值（R 點、孔底、安全高度）照讀照畫，不會去猜。**預設「迴轉中心在 Y0 Z0」**，
  也就是四軸的標準對刀方式（G54 的 Y0／Z0 對在夾頭中心線）——這樣的話什麼都不用填。
- 如果對刀不是這樣（例如 Z0 對在圓棒最頂端），到「素材與設定」的「第四軸」把迴轉中心 Z 填成
  「−半徑」，圖會立刻重畫。沒填而實際不同時，會看到「刀尖穿過迴轉中心線」的提示。
- 這組參數**跟著程式存**（每個 O 號一份）。工件直徑留空 = 由程式推估（只影響 3D 圓棒畫多粗）。
- 會檢查**分度孔是不是都在同一條母線上**——不是的話代表刀是斜著切進圓周的，會警告。
- 位址只支援 `A`；`B`／`C` 出現時警告不模擬。

**模擬**

- 材料是高度圖（每格記一個高度），所以側凹、鑽穿之後的孔壁這類形狀表現不出來。
- 格網只涵蓋素材的 XY 範圍，**完全落在素材外的治具（例如虎鉗鉗口）不會進高度圖，也就抓不到撞鉗口**。
- 時間估算 = 切削長度÷F ＋ 快速長度÷G0 速率 ＋ 停留，不含加減速、換刀時間、主軸啟停。實際會比估的久。
- 素材是推估的時候，判定分兩段：干涉位置落在「程式真的有切到的範圍」之外 → 降成警告
  （那一圈料是猜出來的）；落在裡面 → 維持紅字，但 detail 會註明依據是推估素材。
- 碰撞（R27）的門檻：干涉小於 max(0.2 mm, 一個格距) 不報（粗銑留量與格網量化誤差就有這個等級）；
  「下刀終點停在材料裡」超過 0.5 mm、「路徑掃過材料」超過 2 mm 才是紅字，中間是警告。
  兩個門檻可用 `settings.collisionIgnoreMm` / `collisionErrorMm` 調。

**介面**

- 軟極限（`softLimits`）目前只能從程式碼給，設定面板還沒有欄位，所以 R33 平常不會啟動。
- 「＋ 登記其他刀」登記進來的鄰居刀（別支程式的刀）沒有直徑資料，只能當「佔著大徑刀該淨空刀位」的一方；
  如果隔壁刀位放的是別支程式的大徑刀，這個方向抓不到——要抓得到需要一份跨程式的刀庫刀具主檔。
- 刀庫剛啟用、刀位還沒填時，每把刀會各出一則「刀庫清單裡沒有 T… 的位置」提醒（刀庫面板自己摺成一行，錯誤清單仍逐則列）。
- 刀具表 CSV 裡寫成 `8?` 這類「數字加問號」的格子匯入時會被跳過（只吃得下純數字），
  但畫面會明確告訴你是哪幾把刀的哪一欄沒進來。
- 沒有折疊、沒有搜尋取代、沒有復原以外的版本管理。

## 要填哪些現場資料，結果才會準

程式檔本身只寫了「走到哪裡」，機台裡的東西它一概不知道。下面這些填進去之後，檢查結果才會從「可能」變成「確定」：

1. **真實素材尺寸與擺放位置**（每支程式各一組）。沒填的話全部是從切削範圍推估的，工件外圍那一圈料實際上可能不存在。
2. **夾治具的位置與高度**（虎鉗、壓板、墊塊）。填了才驗得到快速移動會不會掃到壓板——注意目前只抓得到落在素材範圍內的治具。
3. **刀具表的實際值**：直徑、刀尖／倒角角度、刃長、伸出長。程式註解寫的直徑和機台上實際裝的常常不一樣（註解寫 12MM、實際裝 8MM 這種），而這一項會直接改變補正後的路徑。
4. **各 D 號的機台現值**（半徑形狀與摩耗）。用到 G41/G42 又沒填的話，補正路徑只能用公稱直徑硬算。
5. **素材範圍和程式對不上時要回頭確認**：例如孔的位置落在素材外面，通常是素材尺寸或原點位置填錯，不是程式有問題。
6. **機台參數**：G0 實際速率、G83 的餘隙（參數 5115，目前用預設 0.5 mm）、補正先讀節數（參數 19625）、軟極限行程、刀庫刀位配置。
7. **G28 參考點在工件座標的位置**（目前用 X0 Y0 Z150 顯示）。
